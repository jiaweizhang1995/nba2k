## 本跑抓到并修复的引擎 bug（价值所在）

1. **轮换跨年丢失**:`startNewSeason` 重建 phaseState 只保留 userTeamId/deadCap,rotation 每季被清。后果在 S3 爆发——Reaves 从 FA 签回后 role=BENCH，自动轮换把他挤到 7.8 分钟（86 评二当家！),S3 开局 14-29。修复：rotation 跨年保留 → S4 起 Reaves 回到 32 分钟。**这是 49→26 那类崩盘的真正机制之一**——篮网跑时也中过招而不自知
2. **FA 签约角色卡死 BENCH**：所有签约路径都盖 BENCH 且只有交易路径重算。修复：抽 `roleForRank`/`recomputeTeamRoles`，开季全联盟重算 + 签约后即算
3. **顶薪球星数学上签不下**：要价≥顶薪且有竞争时，`evaluateOffer` 兴趣度恒 <62，报价又不能越 max——Luka 差点直接流失。修复：母队 incumbent 忠诚加成 +10（鸟权+第5年保障本来就是母队杠杆）,Luka 5 年顶薪留队，兴趣度 71

## 对评测设计的启示

- **AGENT 模式下观察已经够用**：战绩/士气/伤病/薪资线/市场侦察都可见；position 冲突不会吃掉分钟（pickCourt 不按位置）, 真正的问题是轮换持久化
- **过程分对"按兵不动"不友好但合理**：五年 0 成交换来 tradePnl=0、选秀加成 0（高顺位都自用）——91 分里 25 分是西决结果分。纯过程看其实平平
- **clutch variance 依然偏宽**：S2 的 37 胜有 Luka 伤病因素，但也叠加运气；波动让"持续好运营"和"一季风调雨顺"仍有区分度
- **暴露面还有空间**：先签后换、买断市场、非保障年依然缺失；截止日只给了 1-2 次主动交易窗口，时间太短
