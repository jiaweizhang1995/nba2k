## 为什么还是没夺冠（诚实复盘）

1. **顶层战力差一档**：收官最强 Castle 87，而争冠队标配 88-91 超巨（Haliburton 拿了 MVP）。全队是"深度队"不是"巨星球"——常规赛虐菜稳（57 胜），季后赛高端局攻坚没人。
2. **老鹰天克**：三次季后赛相遇 1-2，且 2029 次轮 0-4 被横扫、2030 首轮 2-0 被翻盘。引擎里老鹰的阵容恰好克制奇才的双塔+后卫群配置。
3. **自由市场没捡到真超巨**：修复后 AI 不再底薪抢人，市场确实公平了——但 Wemby/LaMelo 级别的鱼要价 30-40M，超帽球队根本够不着。公平≠可得。
4. **选秀池方差大**：2028 届有货（21 顺位 Lindqvist 兑现），2029-2031 三届乐透后全是 44-67 评分的边角料——确定性生成的选秀池质量波动偏大。

## 本轮模拟中新发现并已修复的 bug（`bfbb873`）

1. **选秀顺序不认交易归属**：`prepareDraft` 用战绩顺序直接当选秀顺序，交易来的签被原队顶替。已改为按 picks 表真实归属生成——本档手动修复后，独行侠的 22/24 号签成功为奇才所用。
2. **二奢线球队连底薪都签不了**：`canAfford` 的二奢线 return 写在底薪特例判断**之前**，顺序反了。修复后底薪特例正常生效（Hinson 等四连签靠的就是它）。
3. **死钱跨年蒸发**：`startNewSeason` 重建 phaseState 只保留 userTeamId，`deadCap` 整棵被清。已改为过滤过期条目后保留——裁员死钱现在诚实跨年。

## 仍未修的引擎怪癖（记录在案）

- **ROY 评给了 34 岁的 Kyrie**（2027）：`yearsPro` 或新秀资格判定有明显数据问题。
- **合同到期球员原地复活**：AD 和 Kyrie 的存库合同止于 2029，2030 后仍显示 3 年约且评分骤降仍在阵中——续约回写路径疑似生成"幽灵合同"（本轮已把续约产物补全为完整 Contract 类型，现象待复查）。
- **AI 交易估值漂移**：CLE 曾把 72 评分的 Tre Mann 估出 63 点价值，合同/角色权重可能失衡。
- **选秀池强度方差**：连续三年乐透后无 70+ 苗子，合成池的评分分布可能需要校准。

*Bottom line：五年 0 冠，但每一季都有竞争力、每个休赛期都有操作空间。修复后的引擎对"会运营的 GM"是公平的——奇才离东决只差一轮，离冠军差一个 88+ 的超巨。*
